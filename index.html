Getting a menu file
  1. Vanilla menus live in Starfield - Interface.ba2. Extract it with Bethesda Archive Extractor or the Creation Kit's Archive2, and look in Interface/.
  2. Mod menus (like a quick loot mod) ship as loose files: Data/Interface/…/*.swf.
  3. Open the .swf here, click an element, then drag it, resize it with the handles, or type values in the inspector. The inspector also sets opacity and tint, recolours shapes, and edits text fields (wording, colour, size, alignment, box size).
  4. Menus often load other files (shared widgets, button art, fonts). Add them with Linked files, or pick your whole extracted Interface folder, to see those parts. They're shown for reference only; export writes just the menu you opened.
  5. Export saves a .zip with the edited .swf under the same name. Put it back at the same path under Data/Interface/.

Positions set by ActionScript at runtime override the layout saved here. If an element snaps back in game, its code moves it.
